SKILLPATH AI - LOCAL PROJECT PACKAGE
===================================

REQUIREMENTS
- Windows 10/11
- Node.js 18 or newer (Node.js 22 LTS recommended)
- npm (included with Node.js)

START THE WEBSITE
1. Extract this ZIP into a normal folder, for example C:\SkillPathAI.
2. In VS Code choose File > Open Folder and open the extracted folder itself.
3. Confirm package.json is visible in the VS Code Explorer at the top level.
4. Open Terminal > New Terminal.
5. Run: npm install
6. Run: npm start
7. Open: http://localhost:3001

You can also double-click start-local.bat. It checks for package.json and Node/npm,
installs Express when needed, and starts the server on port 3001.

IF PORT 3001 IS BUSY
In PowerShell run: $env:PORT=3002; npm start
Then open http://localhost:3002

FEATURES INCLUDED
- Skills catalogue with categories and beginner/intermediate/advanced levels.
- Typing practice with levels, timing, speed/accuracy feedback and local progress.
- Learning roadmaps with ordered learning steps.
- Ideas into Projects: project cards for portfolio, weather, expense tracker, study assistant,
  spam detector, cybersecurity dashboard, skill recommendation, chat, attendance and energy.
  Choose Create Project Plan to send the selected idea to the built-in local mentor.
- Local mentor: answers common learning questions and produces a project plan with goals,
  technology suggestions, features, starter folder structure, development steps and test checklist.
- No external AI API key or paid AI service is required. Mentor responses are rule-based/local,
  not generated by a remote AI model.
- Typing progress is stored in this browser using localStorage.

API HEALTH CHECK
Open http://localhost:3001/test. A working server returns JSON confirming the server and port.

COMMON FIXES
- ENOENT package.json: you are in the wrong folder. Use cd C:\SkillPathAI (or your extraction
  path) and check with: dir package.json. Do not run npm from Downloads' parent folder.
- Port in use: use the PORT=3002 PowerShell command above.
- npm install fails: check internet access, then run npm cache verify and npm install again.
- Node not found: install Node.js 18+ and reopen VS Code/Terminal.

This is a local learning project. It does not include user accounts, cloud sync, a production
 database, or a remote generative AI service.
